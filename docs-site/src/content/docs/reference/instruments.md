OpenNord is built for the whole Nord line. The **Nord Stage** series comes
first, and the **Stage 4** is the most complete.

The app's **Compatibility** page always has the current state; this page is a
summary. ✓ means tried on a real instrument; ● means built and ready to test,
but not yet tried on one. See [Compatibility](/docs/guide/compatibility/).

## Nord Stage

| Model | Read programs | Samples | Copy from Nord | Send · Delete · Back up |
|---|---|---|---|---|
| **Stage 4** | ✓ | ✓ `.nsmp4` | ✓ | ✓ |
| **Stage 3** | ✓ | ✓ `.nsmp3` | ✓ | ✓ |
| **Stage 2 / 2 EX** | ✓ | ✓ | ✓ | ● |
| **Stage Classic / EX** | ● | – | ● | ● |

## Other Nords

Read and USB are **ready to test** (●) for these. If you have one, running
[Check my Nord](/docs/guide/compatibility/) and sharing the result helps turn
them into ✓.

| Family | Models |
|---|---|
| **Electro** | Electro 3 / 3 HP, 4, 5, 6, 7 |
| **Piano** | Piano 1, 2, 3, 4, 5, 6 |
| **Grand** | Grand, Grand 2 |
| **Organ** | Organ 3, C2 / C2D |
| **Lead** | Lead 4, Lead A1 |
| **Wave** | Wave, Wave 2 |

The Nord C1 has no program files.

## Opening files from disk

Opening files from a folder or by import is narrower than what OpenNord reads
from a connected Nord today:

- **Import a file…**: Stage 4, 3 and 2 programs.
- **Choose a folder…**: Stage 4 and Electro 6 programs, plus presets, samples,
  pianos and `.ns4b` backups.

Programs from the other models open when they are read from the keyboard. See
[File types](/docs/reference/file-types/).

## Moving programs between models

A Stage 2 or 3 program can be converted into a Stage 4 one; see
[Convert to Stage 4](/docs/guide/convert/). A program can only be sent to the
model it was made for.
